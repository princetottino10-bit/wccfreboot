# フェーズ1 実装計画：30秒のゴールシーン

状態：**承認済み・実装中**（2026-10-11）

決まったこと：
- 実機確認は GitHub Pages（公開リポジトリ `princetottino10-bit/wccfreboot`、main のルートから配信）→ https://princetottino10-bit.github.io/wccfreboot/
- FBX → glb の変換は手元の Blender 4.5 LTS をスクリプトで使う
- 公開リポジトリなので、Mixamo 素材を入れる段階で配布形態を確認し直す

## 1. 方針の要点

- **sim と描画を最初から分ける。** 台本再生とボール物理（Rapier）を `src/sim/` に置き、60Hz の固定刻みで状態を進める。描画は毎フレームその状態を読んで、前後の刻みの間を補間して表示するだけにする。フェーズ2の試合エンジンは、台本再生の部分を差し替える形で入る。
- **リプレイは再実行で作る。** 台本・乱数の種・入力を記録しておき、ゴール後に sim を巻き戻して再実行する。描画側はカメラを差し替えて同じ状態を見るだけ。
- **シェーダーは TSL で書く。** three.js の `WebGPURenderer` は WebGPU が使えない端末で自動的に WebGL2 に切り替わる。芝やネットのシェーダーを TSL（three.js のノード記法）で書けば、1本のコードで両方に対応できる。GLSL と WGSL を別々に書く必要がない。
- **仮素材はコードで作る。** 選手のマネキン、骨格、走りのモーション、スタジアム、ボール、仮の音（Web Audio で合成した歓声）をコードで生成する。ライセンスの心配がなく、本番素材が `assets/` に置かれたらそちらを優先して読む。
- **骨格は Mixamo の骨名に合わせる。** 本番のモデルとモーションを Mixamo 系でそろえると、リターゲットなしでそのまま使い回せる。

## 4. 画質プリセットの初期案

実機で計測して調整する。数字は出発点。

| 項目 | 高（WebGPU） | 中（WebGL2） | 低 |
| --- | --- | --- | --- |
| 描画解像度 | 端末解像度 ×0.85 | ×0.7 | ×0.55 |
| 影 | 照明塔4本ぶんの影を合成（2048） | 主光源1本（2048）＋接地影 | 接地影のみ |
| 観客 | 約20,000体 | 約10,000体 | 約4,000体（遠景はテクスチャ） |
| ブルーム | あり | あり（軽量） | なし |
| 選手 LOD0 を使う距離 | 寄りカメラ時 | 寄りカメラ時の近い数人 | 使わない |

「芝に落ちる複数の影」は本物の影マップを4枚持つと iPhone では重い。高でも主光源1本の本物の影に、残りの照明塔ぶんは選手の足元に薄い影の板を方向をずらして描く方法を併用する見込み。

## 5. 用意してほしい素材

なくてもフェーズ1の仕組みは仮素材で全部作れる。届いたものから差し替える。

### 必須（見栄えの基準を満たすのに必要）

1. **選手モデル 1体**（全員で共有）
   - 形式：.glb（.fbx でも可。こちらで変換）
   - 骨格：Mixamo の標準骨格（`mixamorig:Hips` など）。指の骨は省略可
   - ポリゴン数の目安：寄り用 8,000〜12,000 三角形 / 中継用 3,000〜4,000 / 遠景用 800 前後。寄り用だけもらえれば、残り2段階はこちらで減らして作ることも試す
   - T ポーズ、メートル単位、Y が上
   - UV：ユニフォーム（シャツ・パンツ・ソックス）と肌・髪が別の領域に分かれていること。名前と背番号を背中に重ねるので、背中の UV が歪んでいないこと
   - テクスチャ：ベースカラー 1024〜2048px、可能なら法線マップ（服のしわ）
2. **基本移動のモーション（Mixamo）**
   - FBX、「Without Skin」、30fps、**In Place にしないもの**（足の滑りを消すのにルートの移動量を使う）
   - 待機、歩き、ジョグ、ラン、全力疾走、減速して止まる、90° と 180° の切り返し、横移動、後ろ歩き、ゴール後の喜び 2〜3種
3. **サッカー特有のモーション**
   - 右足シュート（強）、インサイドパス、トラップ（足元・胸）、ドリブルのタッチ（ジョグ速度・ラン速度）、スライディング、GK の構え・横っ飛び（左右）・キャッチ
   - 動画から起こすツールの出力は、骨格が Mixamo と同じ名前になる設定で書き出してほしい。違う場合は骨名の対応表を作って合わせる

### あるとよい（なければこちらで作る）

4. **音**：歓声のループ（ざわめき・盛り上がり・ゴールの爆発）、キック音、ホイッスル、ネットに当たる音。WAV か高ビットレートの M4A。CC0 か自作のもの
5. **看板の画像**：架空のブランドのロゴ。こちらで仮のものを作るが、好みがあれば
6. **チームカラーとチーム名**：架空のクラブ2つ（名前、ホームのユニフォーム配色、背番号の書体の好み）

### こちらで作るもの

スタジアム、照明塔、スタンド、ゴール、ネット、ボール、芝、観客の簡略モデル、仮の音。外部の CC0 素材（芝の質感テクスチャなど）を使いたくなったら、ダウンロードの前に確認する。

## 6. 先に決めたいこと

1. **iPhone 実機での確認方法**：WebGPU は HTTPS でしか動かない。PC の開発サーバーに LAN 経由（`http://192.168.x.x`）でつなぐと WebGPU が無効になり、WebGL でしか確認できない。候補は次のどれか。
   - GitHub Pages に確認用ブランチを置き、更新ごとに push して iPhone で開く（推奨。本番と同じ環境）
   - トンネル（cloudflared など）で開発サーバーを一時的に HTTPS 公開する（ツールの追加が要る）
2. **git と GitHub リポジトリ**：このフォルダはまだ git 管理されていない。初期化してよいか、GitHub のリポジトリ名を何にするか。なお、フォルダ名 `wccfreboot　` の末尾に全角スペースが入っている。手元では動くが、リポジトリ名には使えないので別名をつける必要がある。
3. **モーション素材の変換**：FBX を .glb に変換するのに、Blender（手元にあれば）か FBX2glTF（変換ツール。`tools/` に置く）を使いたい。どちらにするか。
