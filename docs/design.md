# 依頼：iPhone向け3Dサッカー育成ゲームの開発（フェーズ1）

iPhoneのSafariで遊ぶ3Dサッカー育成ゲームを、three.jsで新規に作ります。最終目標は「市販のサッカーゲームの中継画面に見える見栄え」です。今回お願いするのはフェーズ1（見栄えの縦切り）だけです。下の全体仕様は、設計判断をするときの前提として読んでください。

## 最初にやること

1. このプロンプトの内容を `docs/design.md` として保存する（以後の全フェーズの設計書）
2. `CLAUDE.md` を作り、技術構成・フォルダ構成・守ること（このプロンプト末尾）を要約して書く
3. フェーズ1の実装計画（作るファイル、順番、私に用意してほしい素材）を出し、私の確認を取ってから実装に入る

## 全体仕様

### 方針
- 遊ぶ端末：iPhoneのSafari（横持ち）。ホーム画面に追加してアプリのように起動する
- 配布：URLを共有するだけ。App Storeは使わない
- 見栄え最優先。基準は「30秒のゴールシーンを動画で撮って知らない人に見せたら、市販ゲームだと思うか」
- 権利：実在のクラブ名・選手名・エンブレム・リーグロゴ・スポンサーは使わない。選手は全員架空
- 人が手で行うのは素材の調達と、iPhone実機での見た目の判断だけ。それ以外はコードとテキストで完結する構成にする

### オリジナリティ：「戦術が育つサッカーゲーム」
既存のサッカーゲームとの違いは、次の2本柱で出す。フェーズ1では実装しないが、試合エンジンとデータ構造はこれを前提に設計すること。

1. **戦術を描く（試合中）**：右上の縮小布陣をタップすると拡大し、選手の位置をドラッグで動かせる。加えて、最終ラインの高さ、プレス開始位置、各選手が使うレーン、サイドバックが中に絞るかどうか、を線や領域で描ける。描いた戦術は3Dの試合で選手の動きとして目に見えて表れる
2. **役割を覚えて育つ（育成）**：能力値に加えて、「偽サイドバック」「内に絞るウイング」「下りてくるセンターフォワード」などの役割習熟度が、その役割で出場するほど伸びる。同じカードでも使い方で別の選手に育つ

支える要素：
- 実況・解説が自分の戦術を拾う（例「右のハーフスペースを使い続けていますね」）。セリフの型をあらかじめ音声で用意し、試合データから選んで流す
- 友達のチーム（布陣・戦術・育てた選手）をサーバーに置き、AIが動かして非同期で対戦する

### 技術構成
| 役割 | 使うもの | 補足 |
| --- | --- | --- |
| 3D描画 | three.js のWebGPUレンダラー | iOS 26未満向けにWebGLの画質設定を用意 |
| 後処理 | ブルーム、色調補正、被写界深度（リプレイ時のみ） | |
| ボールの物理 | Rapier | 選手は物理で動かさず、アニメーション主導 |
| 試合エンジン | 自作（JS） | 描画から完全に切り離し、画面なしでも試合を進められること |
| 選手アニメーション | 自作の制御 | モーションマッチング、足のIK、ボール接触の同期 |
| ログイン・セーブ | Supabase | フェーズ3から |
| 公開 | GitHub Pages ＋ サービスワーカー | ビルドなしの素のHTML/CSS/JS、ライブラリは `vendor/` に同梱、import mapで読み込む |
| 3Dデータ | glTF（.glb）、テクスチャはKTX2 | iPhoneのメモリ節約 |
| テスト | `node --test` | 試合エンジンは画面なしの単体テストを先に書く |

試合エンジンと描画を切り離すことが最重要。試合エンジンは決められた刻み（固定タイムステップ）で状態を進め、描画はその状態を読むだけにする。こうすることで、リプレイは「同じ入力と乱数の種を再生する」だけで作れる。

### 選手モデルとモーション
- 全選手で同じ骨格を共有し、モーションを使い回す
- 距離で3段階に切り替える（寄りカメラ用・中継カメラ用・遠景用）
- ユニフォームの名前・背番号・チームカラーはテクスチャの差し替えで変える
- 基本の移動はMixamo、サッカー特有の動き（トラップ、ドリブルのタッチ、シュート、パス、スライディング、GKのセーブ）は動画からモーションを起こすAIツールと素材パックで調達する（私が用意する）
- 動きを自然に見せる仕組み：
  - モーションマッチング：速度・向き・目標から、手持ちのモーションで一番近い一瞬を探して繋ぐ
  - 足のIK：接地を合わせて足の滑りを消す
  - ボール接触の同期：キックやトラップの瞬間、足が届く位置にボールを先回りさせる
  - 首と上半身をボールや味方の方へひねる

### 試合の見栄え
- カメラ：メインスタンド高めからの中継カメラ。ボールを追ってゆっくり振り、攻撃の局面でわずかに寄る。わずかな手ぶれと望遠の圧縮感
- リプレイ：ゴール・決定機・好セーブの後に自動再生。ゴール裏、低い位置、選手の背中越しの3アングル、スローを交える
- スタジアム：まずナイターを1つだけ作り込む。照明塔の光、芝に落ちる複数の影、ブルーム
- 芝：専用シェーダー。刈り込みの縞、カメラ角度で変わる艶、走った跡の擦れ
- 観客：簡略モデルを大量配置（インスタンス描画）。ゴールで一斉に立ち上がる
- ゴールネット：ボールが入ると揺れる
- 音：実況・解説（ElevenLabsで私が作る）、状況に応じて強弱が変わる歓声、キック音、ホイッスル

### 操作とUI（横持ち）
- 左手：十字キー。ボールに一番近い自チーム選手を動かす。指を離すとAIに戻る
- 右手：シュート（保持中はシュート、守備時はスライディング）
- 右手：GK飛び出し（キーパーがボールへ突進、数秒の待ち時間あり）
- 右上：縮小布陣。タップで拡大して編集。拡大中の試合の扱いは「一時停止」と「スロー進行」を設定で切り替えられるようにする（既定は一時停止）
- スコアと時計は中継の左上表示の形。得点者・交代・カードは中継テロップ風に下から出す
- タッチボタンは半透明で、試合の画を隠さない

### 育成とカード（フェーズ3以降）
- 試合 → 出場時間と活躍で経験値 → 能力と役割習熟度が伸びる → 布陣を組み直して次の試合
- 能力値：スピード、ドリブル、シュート、パス、守備、フィジカル、GK能力。試合エンジンとアニメーション選択の両方が読む
- カード絵は選手の3Dモデルを寄りカメラでレンダリングして作る
- 物理カードは後から：カード裏のQRをカメラで読んで選手を追加

### フェーズ
1. **見栄えの縦切り**（今回）：30秒のゴールシーン
2. **試合として遊べる**：試合エンジン、選手AI、操作、1試合通して遊べる
3. **布陣と育成**：布陣編集、戦術を描く機能、経験値と役割習熟、Supabase保存
4. **演出の拡充と配布**：入場、テロップ、ゴールパフォーマンス、QR読み取り、友達への配布

各フェーズは完了基準を満たすまで次に進まない。

## 今回の作業：フェーズ1「30秒のゴールシーン」

遊べなくてよい。決められた流れのゴールシーンを、中継のような画で再生できることが目的。

### 作るもの
1. ナイターのスタジアム1つ（ピッチ、ゴール、揺れるネット、照明塔、スタンド、看板の差し替え枠）
2. 芝のシェーダー
3. 22人の選手（仮のモデルでよい。後で差し替えやすい読み込みの仕組みにする）とユニフォームのテクスチャ差し替え
4. アニメーション制御の土台：走り・切り返し・シュートの繋ぎ、足のIK、ボール接触の同期
5. ボールの物理（Rapier）
6. 中継カメラと、ゴール後の3アングルリプレイ
7. 観客のインスタンス描画とゴール時の反応
8. 歓声とキック音の再生の仕組み（音素材は仮でよい）
9. 画質設定（WebGPU高・WebGL中・低）と、画面上のFPS・描画数の表示（開発時のみ）
10. 決められたゴールシーンの台本データ（誰がどこへ走り、どこでパスとシュートをするか）。試合エンジンがない段階でも、この台本で選手とボールを動かす

### 完了基準
- iPhone実機（iOS 26）のSafariで、30秒のシーンからリプレイまで止まらずに再生できる。目標は30fps以上（実機で計測し、届かなければ何を削れば届くかを報告する）
- 選手の足が芝の上で滑って見えない。シュートの瞬間に足とボールが合っている
- 私が録画した動画を見て、見栄えの基準（上の「方針」）を満たしていると判断する

### 素材について
- モデルやモーションが手元にない段階は、仮の素材で仕組みを先に作る。仮素材は差し替える前提で、`assets/` 配下のファイルを置き換えるだけで反映されるようにする
- 私に用意してほしい素材（形式・骨格・ポリゴン数の目安）は、計画の段階でリストにして出す
- ライセンスが不明な素材は使わない。使った素材は `assets/CREDITS.md` に出典とライセンスを書く

## 守ること
- 実在のクラブ名・選手名・エンブレム・リーグロゴ・スポンサーを、コードにも素材にも入れない
- 試合エンジン（後のフェーズ）と描画は切り離す。描画側に試合のルールや判定を書かない
- 大きな設計判断（ライブラリの追加、フォルダ構成の変更、仕様にない機能）は、実装前に私に確認する
- 作業の区切りごとに、何ができて何が残っているか、iPhone実機で確認してほしい点を短く報告する
